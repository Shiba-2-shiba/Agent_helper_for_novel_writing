# Skill Router Smoke Prompts (2026-03-05)

1. Idea
- Prompt: 新しい小説案を出したい。異世界転生でコメディ寄りにしたい。
- Expected Skill: idea-generator

2. Bootstrap
- Prompt: このログラインで案件作成して。保存先も決めたい。
- Expected Skill: project-bootstrap

3. Setting
- Prompt: 設定矛盾を解消したい。世界観ルールの整合を見直して。
- Expected Skill: setting-creator

4. Scene Plan
- Prompt: 次の2シーンの段取りだけ決めたい。本文はまだ書かない。
- Expected Skill: scene-planner

5. Draft
- Prompt: 第3章2シーンを書いて。新規本文の初稿がほしい。
- Expected Skill: novel-writer

6. Revision
- Prompt: このシーンを改稿して。テンポの弱い部分を直して。
- Expected Skill: revision-editor

7. Audit
- Prompt: この章の矛盾チェックをして。弱点も洗い出して。
- Expected Skill: consistency-auditor

8. Polish
- Prompt: 文体を整えて。語尾のブレを減らして読みやすくしたい。
- Expected Skill: prose-polisher

9. Resume
- Prompt: どこから再開すべき？今の進捗を整理して次の作業を決めたい。
- Expected Skill: resume-orchestrator
