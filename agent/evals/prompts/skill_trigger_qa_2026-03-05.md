# Skill Trigger QA Set (2026-03-05)

## idea-generator
### should-trigger
- 新しい小説のネタ出しを手伝って。
- ざっくりした発想しかないから壁打ちしたい。
- アイディアを3案くらい比較したい。
- 世界観は未定なのでまず企画を広げたい。
- ログライン候補を作りたい。
- まだ設定を固めずに方向性だけ決めたい。
- 物語のフックを一緒に考えて。
- ジャンルだけ決まってるので案を増やしたい。
### should-not-trigger
- このログラインで案件作成して。
- 第2章1シーンを書いて。
- このシーンを改稿して。
- 設定資料の矛盾を直したい。
- 次の2シーンを段取りしたい。
- 文章の語尾を整えて。
- 現在地を整理して再開したい。
- この章の問題点を監査して。

## project-bootstrap
### should-trigger
- このログラインで新規案件を作成して。
- プロジェクト名と保存先を確定したい。
- 企画が決まったので箱を初期化して。
- init_project の実行前提で進めて。
- 既存案件に agent 運用だけ追加したい。
- 命名規則に沿って新規プロジェクトを作りたい。
- まず作業フォルダ構成を作ってから進めたい。
- 企画合意済みなので初期化フェーズを進めたい。
### should-not-trigger
- 新しい物語アイデアを出したい。
- 設定の矛盾を解消したい。
- 次シーンの段取りを固めたい。
- 第4章を書いてほしい。
- このシーンをリライトしたい。
- 文章を推敲して読みやすくしたい。
- 整合性チェックだけしてほしい。
- どこから再開するべきか知りたい。

## setting-creator
### should-trigger
- 設定資料を作り直したい。
- 世界観ルールの穴を埋めたい。
- キャラクター動機の土台を固めたい。
- 04_plot_outline を再整理したい。
- 設定とプロットの因果を整えたい。
- 物語の骨格が弱いので設計を見直したい。
- 章方針の前提設定を更新したい。
- long_form_100k の planning gate が blocked なのでシーン在庫を増やしたい。
### should-not-trigger
- とりあえず企画案を複数出して。
- このログラインで案件を初期化したい。
- 次の2シーンの段取りを決めたい。
- 第1章3シーンを書いて。
- このシーンを改稿して。
- 文体を整えて仕上げたい。
- まず矛盾診断だけして。
- 今どこまで進んだか整理して。

## scene-planner
### should-trigger
- 次の1〜3シーンの段取りを決めたい。
- 本文は書かずにシーン設計だけしたい。
- 次章をシーン分解して着手順を決めたい。
- 直近執筆用のビートを作って。
- Write Next を1つに絞りたい。
- runtime を参照して段取りを再整理したい。
- 章全体の流れを執筆前に固めたい。
- 次のシーン候補を比較して決めたい。
### should-not-trigger
- 新規企画のアイデアを出して。
- このログラインで案件作成したい。
- 世界観設定を作り込みたい。
- planning gate が blocked の間は次シーンの段取りへ進めたくない。
- 既存シーンの改稿をしてほしい。
- 文章の推敲だけお願いしたい。
- まず矛盾監査をしてほしい。
- 再開時の現在地を整理したい。

## novel-writer
### should-trigger
- 第2章1シーンを書いて。
- 続きの本文を執筆して。
- この章の新規シーン初稿を作って。
- runtime-first で新規執筆したい。
- 1000-1500文字で次シーンを書いて。
- draft_prompt を使って本文生成して。
- chapter 5 scene 2 を新規で書いて。
- planning gate ready なので直前シーンを受けて続きを執筆して。
### should-not-trigger
- 企画アイデアを広げたい。
- 案件の初期化だけしたい。
- 設定資料の整備をしたい。
- シーン段取りだけ先に決めたい。
- 既存本文の改稿をしたい。
- 文体調整だけしたい。
- 整合性チェックだけしたい。
- 再開手順を整理したい。

## revision-editor
### should-trigger
- このシーンを書き直して。
- 展開は維持してテンポだけ改善したい。
- 既存稿の弱点を直して再構成したい。
- 一部を差し替える改稿をしたい。
- 保持点を残して問題点だけ修正したい。
- 会話の温度感を保って改稿して。
- 引きを強くする方向でリライトして。
- 方向性維持で改善版を作りたい。
### should-not-trigger
- 新しい小説案を出したい。
- まずプロジェクトを作成したい。
- 設定構築をやり直したい。
- 次シーンの段取りだけ欲しい。
- 新規本文を最初から書いて。
- 語尾や文体を軽く整えるだけでいい。
- 問題点の監査だけして。
- 次に何をやるべきか整理したい。

## consistency-auditor
### should-trigger
- この章の矛盾をチェックして。
- 設定と本文の不整合を診断して。
- 問題点を優先度付きで洗い出して。
- 破綻しそうな箇所を監査して。
- 感情線の停滞ポイントを指摘して。
- 因果の弱い部分を特定したい。
- 違和感の原因を診断したい。
- 監査結果と修正方針を分けて出して。
### should-not-trigger
- 新規アイデアを出したい。
- ログラインから案件作成したい。
- 設定資料を作り込みたい。
- 次のシーン段取りを固めたい。
- 新規本文を書いてほしい。
- 既存稿を直接改稿してほしい。
- 文体の仕上げだけしたい。
- 再開プランを決めたい。

## prose-polisher
### should-trigger
- 文体を整えて読みやすくして。
- 語尾の揺れを減らして。
- 冗長な説明を圧縮したい。
- 地の文の密度を整えたい。
- 引きの弱い締めを少し強くしたい。
- 構造は変えずに仕上げたい。
- 表現のノイズを取りたい。
- 推敲モードで軽く整えて。
### should-not-trigger
- 企画案をゼロから出したい。
- 合意ログラインで案件を初期化したい。
- 設定矛盾を根本的に直したい。
- 次シーンの段取りを決めたい。
- 新規本文を作ってほしい。
- シーンを再構成する改稿をしたい。
- まず監査で問題点を洗い出したい。
- 再開判断をしてほしい。

## resume-orchestrator
### should-trigger
- どこから再開すべき？
- 今の進捗を整理して次アクションを決めたい。
- 前回の続きに戻るため現在地を確認したい。
- 推奨スキルを1つに絞ってほしい。
- 中断後なので再開順を提案して。
- runtime/resume_brief が古いか判定したい。
- chapter/scene 未指定で再開候補を推定したい。
- いま何を読むべきか Read First を決めたい。
### should-not-trigger
- 新規企画のアイデアを出したい。
- このログラインで案件を作成したい。
- 設定資料を再設計したい。
- 次の2シーンを段取りしたい。
- 第6章1シーンを書いてほしい。
- 既存シーンを書き直してほしい。
- 文体の推敲だけしたい。
- 章全体の矛盾診断だけしたい。
