# 和文の段落診断と原稿書き出し

## 段落数と差分編集の番号は別の指標

`check_report.json` の `paragraph_count` は、**空白だけの行を除いたソース行数**を示す。空行のない「改行＋全角字下げ」の小説本文や、字下げのない会話行も、それぞれ1段落として数える。LFとCRLFに対応し、空行は数えない。`info` にも `definition: nonempty_source_lines` を記録する。

同じ区切りを段落重複・段落長の文体診断に使う。エディタの表示上の折り返しでは増えないが、ファイルに保存された改行は区切りになる。1段落を手動で複数行に折り返した原稿では、その行数を数える簡易指標であり、意味上の段落を推定するものではない。

一方、`build_expand_prompt.py` の `P1` / `P2` と `apply_expand_edits.py` の `TARGET: after P1` は、互換性のため従来どおり**空行で区切った編集ブロック**を指す。`paragraph_count` の番号として流用しない。必ず生成された段落マップの番号と `ANCHOR` を照合する。

## 会話をまたがない文体診断

文境界は句点・疑問符・感嘆符に加え、会話の閉じ括弧 `」` / `』` の後の改行でも区切る。句読点に続く閉じ括弧は直前の文に残す。閉じ括弧のない単なる改行だけでは文を分断しないため、複数行にわたる単文の診断は維持する。空行は文の区切りになる。

`triadic_listing_pattern` の根拠には、元本文の1始まりの `start_line` / `end_line` を付ける。文の境界を直しても、列挙・説明の繰り返し・語尾の反復などの警告そのものを無効化するわけではない。

段落長が均一という警告は、40文字以上の段落を対象に、平均の±12%に収まる段落が5個以上かつ対象の80%以上ある場合に出す。多数の段落のうち5個だけが似ていることを、全体が均一だとは扱わない。

これらは編集候補を示すヒューリスティックであり、意味・自然さ・文学的品質の判定ではない。警告は対象本文を読んで評価する。既存の検査・承認記録をこの変更だけで書き換えることはない。新しい診断が必要なら通常のcheckと、必要なapproveを行う。

## 作品名を指定して書き出す

```sh
python scripts/export_manuscript.py --project my_novel --title "作品名"
```

`--title` は原稿先頭の見出しだけを指定する。省略時は従来どおりprojectディレクトリ名を使う。明示する場合は空でない1行のタイトルを渡す。未定義の作品メタデータから推測しない。Python APIも `export_manuscript(project_dir, title="作品名")` に対応する。

書き出しは各scene txtの全角字下げ、前後の空白・空行、元の改行形式を削除せずに保持する。見出しと場面間の改行は書き出し側で追加する。正本のscene txtは変更しない。

対象は引き続き現在有効な承認を持つsceneのみ。warning採用済みのsceneを含めるには `--include-warnings` を付ける。stale承認を通過させたり、未承認の本文を作品名の指定だけで採用したりすることはない。
