# コンセプトシート (Concept Sheet)

> **クロスリファレンス**: このシートで決めた「軸」と「重点レンズ」は `02_character_sheet.md`・`04_plot_outline.md`・`05_chapter_outline.md` と紐づいています。執筆で迷ったときはここに戻ってください。

このシートは、物語の「核」がブレないようにするための羅針盤です。

> **最低限ここまで埋めれば動けます**: `1. タイトル` から `8. 作品体験の核` まで。
> `9. 展開・演出のバリエーション設計` は必要な場合のみ、`10. 売り` は企画を一言で固定したいときに使ってください。

## 1. タイトル（仮）
> ここにタイトル案を記載します

## 2. ターゲット読者
> 誰に向けて書くのか（例：異世界ファンタジーが好きな10〜20代男性、お仕事小説が好きな20代女性、など）

## 3. ログライン (Logline)
> 物語全体を「1〜2文」で説明してください。
> 例：「[主人公]が[目的]を達成するために、[障害]を乗り越える物語」

## 4. テーマ (Theme)
> 読者に最終的に何を伝えたいか、どういう感情になってほしいか。
> （例：「努力は必ず報われる」「過去のトラウマからの脱却」「痛快な復讐劇でスカッとする」など）

## 5. キーワード (Keywords)
> 作品のジャンルや要素を表す単語を3〜5個挙げてください。
> 例：ハイファンタジー / 魔法学園 / 追放モノ / 主人公最強 / 幼馴染

## 6. 物語の軸 (Axis)
> 主軸/副軸/補助軸を明確にします。比率は目安でOKです。
> → `04_plot_outline.md` の各幕「軸の配分」・`05_chapter_outline.md` の章ごと比率と連動する設定です。
> 例：
> - **主軸**: バトル/成長（比率 7）
> - **副軸**: 関係性ドラマ（比率 2）
> - **補助軸**: ミステリー（比率 1）

## 7. 今回の重点レンズ
> 今回の planning で何を強めるかを明確にします。
> → `02_character_sheet.md` の人物設計、`04_plot_outline.md` の各幕設計、`05_chapter_outline.md` の章運用と連動します。
> 例：関係性重視 / 謎の提示と回収重視 / 成長と達成重視 / 緊張感重視 / ユーモア重視

## 8. 作品体験の核
> 読者に強く感じてほしい体験を整理します。
> **中核の魅力**: どこが一番面白いのか、何を期待して読んでほしいか
> **感情の核**: 読後にどんな余韻や感情を残したいか
> **避けたい方向**: 今回は前面に出しすぎない要素、採用しない演出方針

## 9. 展開・演出のバリエーション設計（必要な場合のみ）
> ワンパターン回避のために、使いたい展開や演出の型を複数用意します。
> → 各型の担当キャラや関係圧力は `02_character_sheet.md`、各幕での使い方は `04_plot_outline.md` で管理します。
> 例：
> - **関係性の型**: 信頼の形成 / すれ違い / 立場の逆転
> - **展開の型**: 発見 / 失敗 / 反転 / 代償の発生
> - **演出の型**: 静かな会話 / 緊張の高まり / ユーモア / 謎の提示
> - **変化の型**: 小さな前進 / 保留 / 悪化 / 意味の反転

### 型リスト（チェック用）
- [ ] 関係性の前進
- [ ] 対立の先鋭化
- [ ] 謎や不穏さの提示
- [ ] ユーモアや緩急
- [ ] 成功と達成感
- [ ] 失敗や代償
- [ ] 情報の誤認や認識のズレ
- [ ] 立場や優劣の逆転
- [ ] 世界設定の制約が効く展開
- [ ] 感情の爆発や告白
- [ ] 伏線の回収
- [ ] 次章への保留や引き

## 10. この作品ならではの「売り」 (USP: Unique Selling Proposition)
> 既存の作品と比べて、どこが新しいのか、どこが一番面白いのかを一言で。

## 11. レンズ別メモ（必要な場合のみ）
> 今回の重点レンズごとに、追加で決めておきたい論点があれば記入します。未採用なら空欄で構いません。
> 例：
> - **関係性レンズ**: 誰と誰の距離がどう変わると一番効くか
> - **ユーモアレンズ**: 緩急をどこで入れるか、何を笑いの源にするか
> - **謎 / サスペンスレンズ**: 何を隠し、どこで開示するか
> - **戦闘 / 競技レンズ**: 勝敗の条件、見せ場、制約
> - **社会 / 制度レンズ**: 組織や制度がどう物語を動かすか
